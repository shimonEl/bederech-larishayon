# לעבור

Built output only. Live at https://shimonel.github.io/bederech-larishayon/

Prep app for the Israeli theory driving exam (licence B), built from the
Ministry of Transport question bank published on data.gov.il. The source lives
in a separate private repository; this repo is regenerated by its deploy script
and force-pushed, so do not edit anything here by hand.
